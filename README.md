# Social Media Narrative Analysis

Sample repository demonstrating computational social science skills for digital political communication research.

## Project Overview
This repository contains sample Python scripts for analyzing social media narratives, classifying political discourse, and detecting polarization patterns. The code demonstrates:
- Text data loading and preprocessing
- Basic sentiment analysis and narrative classification
- Word frequency and topic extraction
- Visualization of narrative patterns
- Sample workflows applicable to X/Twitter, Facebook, Telegram, and TikTok data analysis

## Skills Demonstrated
- Python (pandas, matplotlib, numpy, collections)
- Text preprocessing and cleaning
- Basic sentiment analysis (lexicon-based approach)
- Word frequency analysis and keyword extraction
- Narrative pattern visualization
- Data analysis for political communication research
